# 提示词：最简版（方式 2）

> 复制整段，把 `<...>` 换成你的信息，连同 `SKILL.md` 一起发给 AI（ChatGPT / Claude / DeepSeek / 豆包 都行）。

---

请严格按我附上的 **nexhub-source-gen** 规范，给 NexHub 做一个能直接导入的源。

**站点首页**：`<填首页网址>`
**类型**：`<动漫 / 漫画 / 小说>`
**搜索结果页**：`<可留空>`
**详情页**：`<可留空>`

**要求**

1. 先判断这个站属于哪种情况，把判断依据写一行给我：
   - A 自带数据接口
   - B 普通网页（打开源码就能看到内容）
   - C 要浏览器渲染（源码里是空的）
   - D 有人机验证（滑块 / 图形码 / Cloudflare）
   - E 域名已经没站了（打开只有服务器默认页）
2. 只做「搜索 + 详情」这两步，先跑通；目录、图片、播放等我确认后再加。
3. 输出两样东西：
   - 一个完整的 `.json` 文件内容（不要省略号，不要伪代码）
   - 3 步验收说明（我该点哪里、看什么）
4. 拿不准的字段不要编，直接问我；站点结构看不清就让我保存网页源码给你。
5. 遇到验证码**不要尝试绕过**，告诉我"需要用户在 App 里手动点一次"。

---

## 拿到回答之后

1. 把 JSON 存成 `随便起个名.json`（UTF-8）。
2. NexHub →「源管理」→ 右上角 **+** → 导入文件。
3. 按 AI 给的 3 步验收；哪步不对，按下面格式回它：

```
哪一步：首页 / 搜索 / 详情 / 目录 / 播放 / 图片
现象：空白 / 报错文字 / 图裂 / 一直转圈
截图：<附上>
```
