# 提示词：只给一个网址（最省事的起点）

> 你手上只有一个链接，别的都不知道？用这段。
> 注意：成功率低于"给 3 个链接"，但 AI 会自己想办法，并且会告诉你缺什么。

---

## 复制这段发出去

```
我想给 NexHub 加一个源，现在只有站点网址：
<填首页网址>

我的情况（照实选一个）：
- 我完全不懂技术，不知道怎么找"搜索结果页"和"详情页"
- 我能打开这个网站，不需要登录

请你：
1. 先判断这个站能不能做（能 / 不能 / 要试了才知道），并说明原因。
   如果打开只有一个服务器默认页（比如 Welcome to nginx），直接告诉我"这个域名已经没站了"。
2. 如果能做，请先只做「搜索 + 详情」两步，给我一个 JSON 和 3 步验收说明。
3. 如果缺信息，用**大白话**问我，最多问 3 个问题；不要让我"看选择器""看 HTML 结构"。
4. 遇到验证码不要尝试绕过，告诉我"到时候我自己点一下验证"。
```

---

## 它可能会问你什么（提前知道就不慌）

| AI 的问题 | 你可以这样答 |
|---|---|
| 「在这个站搜一下任意关键词，把地址栏的链接发我」 | 复制粘贴地址栏，长链接也没关系 |
| 「随便点开一部作品，把地址发我」 | 同上 |
| 「打开页面后是不是要等一两秒才出内容？」 | 是 / 不是，照实说 |
| 「站点有没有要求登录？」 | 有 / 没有 |

---

## 做完之后

1. 存成 `xxx.json` → NexHub「源管理」→ **+** → 导入文件。
2. 首页下拉刷新，找到这个源。
3. 试「搜一个词 → 点开一部 → 能看」这三步。

哪一步不对，回去告诉 AI：**哪一步 + 什么现象 + 截图**。
