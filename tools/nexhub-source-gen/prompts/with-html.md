# 提示词：带网页源码版（方式 3，最保险）

> 适合：AI 抓不到页面（要登录 / 要验证 / 网络不通），或者 AI 说"看不清结构"。
> 你不需要看懂源码，保存下来丢给 AI 就行。

---

## 第 1 步：保存几个页面

**Chrome / Edge**：打开页面 → 右键 → **另存为** → 文件类型选「网页，仅 HTML」→ 保存。
**手机浏览器**：菜单里找「保存网页 / 下载页面」，或用电脑操作更省事。

建议按顺序保存（能存几个存几个）：

| 页面 | 怎么找 |
|---|---|
| 首页 | 直接打开站点首页 |
| 搜索结果页 | 在站内搜任意一个词（比如「都市」）后的地址 |
| 详情页 | 随便点开一部作品 |
| 目录页 / 播放页 / 阅读页 | 详情页里点「开始阅读 / 播放」进入的那一页 |

---

## 第 2 步：发给 AI（复制这段）

```
我用浏览器保存了下面这些页面的 HTML，请据此给我做一个 NexHub 源。
只使用这些 HTML 里真实存在的结构，找不到的字段请直接说"不确定"，不要编。

类型：<动漫 / 漫画 / 小说>

附件对应关系：
- 首页：<附件 1>
- 搜索结果页：<附件 2，没有就删掉这行>
- 详情页：<附件 3>
- 目录/播放/阅读页：<附件 4，没有就删掉这行>

要求：
1. 先在回答开头用一句话说明：这个站是普通网页、还是靠脚本渲染的（依据是附件里能不能直接看到作品标题/链接）。
2. 只输出一个完整 JSON + 3 步验收说明。
3. 先只做「搜索 + 详情」，跑通后我再让你加目录和播放。
4. 遇到验证码不要尝试绕过。
```

---

## 第 3 步：导入 + 验收

1. 保存为 `xxx.json`（UTF-8 编码）。
2. NexHub →「源管理」→ **+** → 导入文件。
3. 按下面清单试：

- [ ] 搜索能出结果，卡片有封面
- [ ] 点进详情，标题和网页一致
- [ ] 没有出现"每张卡片点进去都是同一部"

有任何一条不对，把那一条的现象 + 截图发给 AI，并把对应的 HTML 再附一次。
