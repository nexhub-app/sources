# NexHub 源生成助手

**一句话：把一个网址发给 AI，它给你一个 `.json` 文件，导入 NexHub 就能看。**

不用会编程，不用改 App，不用装开发环境。这个文件夹是一套「让 AI 帮你做源」的说明书 + 工具：AI 读它，就知道 NexHub 的源该怎么写、怎么自查、怎么少踩坑。

> 适用：动漫 / 漫画 / 小说站点。影视短剧同理（类型选「动漫」）。

---

## 这个技能能做什么

| 能做 | 说明 |
|---|---|
| 从零写一个源 | 给网址 + 类型，产出可导入的 `.json` |
| 补齐一个半成品源 | 已有搜索没有详情、有详情没有播放，接着往下写 |
| 修坏掉的源 | 「搜索空了」「封面没了」「播不了」「没有分类」都能查 |
| 判断站点能不能做 | 先探测：自带接口 / 普通网页 / 要浏览器渲染 / 有人机验证 / 域名已死 |
| 生成全功能骨架 | 评论、登录、网络、收藏、公告、周更表、猜你喜欢、筛选全列齐，留 TODO 给人填 |
| 自检 | 跑脚本查字段名、脚本入口、占位符、重复键，0 ERROR 才算过 |

**做不到**（也别让它试）：绕过滑块/图形验证码、破解付费墙、抓取要登录才可见的内容、恢复已经关停的网站。

## 怎么跟 AI 开口（照抄就行）

> **做新源**
> 帮我做个 NexHub 源，站点是 `https://xxx.com`，我想看漫画。搜索页是 ……，详情页是 ……

> **修旧源**
> 这个源的搜索不出结果了（附 json），站点是 `https://xxx.com`，帮我看是哪一步断了。

> **只想知道能不能做**
> `https://xxx.com` 这个站能不能做成 NexHub 源？先别写，告诉我你的判断依据。

> **要全功能骨架**
> 按 nexhub-source-gen 规范给我一份覆盖评论/登录/收藏/筛选的全功能源骨架，先留 TODO。

## 一、你只需要准备 3 样东西

| # | 准备什么 | 说明 |
|---|---|---|
| 1 | **站点首页网址** | 例：`https://www.example.com` |
| 2 | **想看什么** | 动漫 / 漫画 / 小说，三选一 |
| 3 | **两个页面链接**（可选，但强烈建议） | ① 在这个站搜个词后的**搜索结果页**链接 ② 随便点开一部作品的**详情页**链接 |

有第 3 项，成功率高很多；没有也能做，但可能要多试几次。

## 二、四种让 AI 帮你做的方式（任选一种）

### 方式 1｜在 WorkBuddy 里装成本地技能（最省事，推荐）

装一次，以后每句话就能用。

**第 1 步**：把本文件夹放到电脑上固定位置（例如 `E:\repos\sources\tools\nexhub-source-gen`）。

**第 2 步**：在 PowerShell 里粘一次下面这段（路径改成你自己的），回车：

```powershell
New-Item -ItemType Junction `
  -Path   "$env:USERPROFILE\.workbuddy\skills\nexhub-source-gen" `
  -Target "E:\repos\sources\tools\nexhub-source-gen"
```

macOS / Linux 用一条软链代替：

```bash
mkdir -p ~/.workbuddy/skills
ln -s /path/to/nexhub-source-gen ~/.workbuddy/skills/nexhub-source-gen
```

**第 3 步**：打开 WorkBuddy，直接说话：

> 用 nexhub-source-gen 帮我做个源，站点是 https://xxx.com ，我想看漫画。
> 搜索页是 ……，详情页是 ……

AI 会自己判断站点类型、写 JSON、跑自检，然后把文件和验收步骤给你。

---

### 方式 2｜不装任何东西：复制提示词给任意 AI

ChatGPT / Claude / DeepSeek / 豆包 都行，只要能把 `SKILL.md` 发给它（附件、粘贴、或给个链接）。

**第 1 步**：把本文件夹里的 `SKILL.md` 附给 AI（或让它读这个仓库）。
**第 2 步**：从 `prompts/` 里挑一个现成的（`only-url.md` / `quick.md` / `with-html.md`），或直接粘下面这段：

```
请严格按我附上的 nexhub-source-gen 规范，给 NexHub 做一个能直接导入的源。

站点首页：<填这里>
类型：<动漫 / 漫画 / 小说>
搜索结果页：<可留空>
详情页：<可留空>

要求：
1. 先判断站点属于哪种（自带接口 / 普通网页 / 要浏览器渲染 / 有人机验证 / 域名已停用），说明你的判断依据，再动手写。
2. 只输出两样东西：一个完整 JSON、以及 3 步验收说明。不要解释代码，不要贴截图。
3. 拿不准的字段不要编，直接问我。
4. 遇到验证码不要尝试绕过，告诉我让用户自己在 App 里点一次。
```

**第 3 步**：把 AI 给的 JSON 存成 `xxx.json`，按第三节导入。

> 换 AI 时同样的提示词可以复用；`references/` 里几篇文档（字段、选择器、脚本、排障）是给 AI 补充细节用的，卡住时一并发给它。

---

### 方式 3｜最保险：把网页源码直接给 AI（站点打不开 / AI 猜不出来时用）

有些页面 AI 抓不到（要登录、要验证、要挂代理），那就给它「原件」。

**第 1 步**：浏览器打开该页面 → 右键 → **另存为** → 保存类型选「网页，仅 HTML」。
**第 2 步**：把保存的 `.html` 拖进对话，附上这段：

```
我用浏览器保存了这几个页面的 HTML，请据此生成 NexHub 源：

首页 html：<附件 1>
搜索结果页 html：<附件 2，可留空>
详情页 html：<附件 3>
播放页/阅读页 html：<附件 4，可留空>

类型：<动漫 / 漫画 / 小说>
要求：只用我给的 HTML 里真实存在的结构，找不到就说不确定；输出 JSON + 3 步验收说明。
```

**第 3 步**：同样存成 `.json` 导入。

---

### 方式 4｜进阶：让 AI 用仓库里的脚本自动探测（AI 侧有 Python 时）

这层不用你动手，是给 AI 看的；你只要说一句：

> 先跑仓库里的 scripts/probe_site.py 判断这个站怎么抓，再写源，最后用 scripts/validate_source.py 自检。

AI 会执行：

```bash
python scripts/probe_site.py https://站点首页 --save page.html
# …写源…
python scripts/validate_source.py 我的源.json
```

- `probe_site.py`：告诉你这站是「自带接口 / 普通网页 / 要浏览器渲染 / 有人机验证 / **域名已经没站了**」，还会列出列表容器、懒加载图片属性、搜索参数名。
- `validate_source.py`：找出写错的地方（字段名、脚本函数名、占位符、重复键），必须 **0 个 ERROR** 才算过。

## 三、拿到 JSON 之后：导入 3 步

1. NexHub →「源管理」→ 右上角 **+** → 导入文件 → 选那个 `.json`
2. 回首页下拉刷新，看到这个源
3. 按下面的清单试一遍

## 四、验收清单（逐条打勾）

- [ ] 发现页/首页有卡片，封面不是灰块
- [ ] 搜一个关键词能出结果，翻页不重复
- [ ] 点开详情，标题、简介是对的（不是别的作品）
- [ ] 目录/选集条数和网页一致
- [ ] 漫画图片能加载、顺序对；或视频能播放
- [ ] 关掉 App 再打开，仍然正常

有一条不对，就把「哪一步 + 现象 + 截图」发回给 AI，让它只改那一处。

---

## 五、出问题怎么反馈（照抄这个格式）

```
哪一步：首页 / 搜索 / 详情 / 目录 / 播放 / 图片
现象：空白 / 报错文字 / 图裂 / 一直转圈 / 清晰度很低
截图：<附上>
最近改动：<改了什么之后才坏的>
```

AI 会按「先看站还在不在 → 再看页面结构 → 最后改字段」的顺序排查，通常一次就能定位。

## 六、常见问题

**Q：AI 说「域名已弃用」是什么意思？**
这个网址现在打开只有一个服务器默认页（`Welcome to nginx` 之类），站方搬走了。换新域名再来，或者放弃这个站——这种情况改源没用。

**Q：搜索时弹出验证页，正常吗？**
正常。有些站给搜索加了滑块/图形验证。源里会把搜索配成「浏览器模式」，**你自己点一次验证**就行，之后同一会话不用再点。AI 不会（也不应该）帮你绕验证码。

**Q：视频很模糊怎么办？**
先看播放页有没有「线路」切换，选标着 1080P/720P 的那条。如果最高只有 480P，那是站方免费档就给这个清晰度，源这边改不了。

**Q：为什么没有分类？**
有的站分类页要会员，或者分类是动态加载的。让 AI 再跑一次探测，会在源里加「从首页导航自动发现分类」的逻辑。

**Q：一个源能同时支持搜索和分类吗？**
可以，但建议**先跑通搜索 + 详情**，再加目录、图片、播放。一次全写，出错时很难定位。

---

## 七、给使用者的三条底线

1. **不碰付费墙**：只抓站点公开可见的内容，会员/付费内容不做。
2. **不绕验证码**：遇到人机验证，由你自己在 App 里手动点。
3. **不传播账号**：源里不要写死别人的账号、Cookie 或密钥。

## 八、这个文件夹里都有什么（好奇再看）

```
nexhub-source-gen/
├── SKILL.md                      给 AI 的主说明书（分流、铁律、流程）
├── README.md                     你正在看的这份
├── prompts/                      可直接复制的提示词
│   ├── only-url.md               只有一个网址时（起点）
│   ├── quick.md                  最简版（方式 2）
│   └── with-html.md              带网页源码版（方式 3）
├── references/                   细节手册：字段、选择器、脚本、排障、小白对话剧本
├── assets/templates/             8 套模板，AI 直接改
└── scripts/                      probe_site.py / validate_source.py
```

遇到本 README 没写的情况，直接问 AI；它读 `references/` 就知道怎么处理。
